# 白饭鱼的记忆系统：下期预告

白饭鱼的模型渠道可以切换，记忆仍由同一份独立存储管理。这个分层是本期接入的背景，也是下一期可以继续展开的内容。

当前本地实现包含：

- 保存聊天原文，为回忆保留可追溯的出处。
- 区分人物、事件、事实、主观理解和明确约定。
- 用重要度、情绪唤醒、关系意义与真实回想调整召回权重，结合时间衰减；衰减不等于删除原文，也不会提高事实可信度。
- 对来源撤销和纠错处理关联记忆，避免失效认识继续被使用。
- 反思引用实际经历，形成当前认识或未完念头；允许没有变化。

这些是工程机制，不构成人类记忆、意识或人格成长的科学证明。真实长期效果仍需观察。本仓库没有发布记忆模块、真实聊天、人物档案或私人日记。

适合视频结尾的一句话：

> 换个模型之后，为什么它还记得之前发生过什么？因为记忆是另外一层。我还给白饭鱼做了原文溯源、人物与事件记忆，以及带时间衰减的召回。下一期讲它怎么记、怎么忘，还有记错了怎么办。
