# DeepSeek 一句话接入契约（0.3.0）

目标：在当前 DSH profile 内保持 DeepSeek，通过 OFM 承接后续模型调用，检查账号轮换；缺少任何证据时给出原因和可执行的下一步。免费公开池没有账号，不能把公开池可用报告成账号轮换通过。

## 装载与触发

本包依赖官方 `@ebony-vinyl/dsh-our-free-model@2.8.0`，不是第三方裸名 npm 包。bundle 在没有已有 OFM entry 时自动装载该依赖，使用 managed 分发模式，由包管理器负责其版本；已有 OFM entry 则复用，不重复注册提供商或替换其账号。

安装后可以直接说：

> 让大肥鱼继续使用 DeepSeek，把后续消耗转到 OFM 免费池，保持现在的思考档位，并检查轮换。

模型可发现原生工具 `bfy_ofm_onboard`。不依赖模型推理的命令入口为：

```text
/bfy-ofm onboard
/bfy-ofm onboard qodercn
/bfy-ofm status
```

明确推荐本人已有 qoder、qodercn、trae 等渠道；trea 作为拼写别名识别为 trae。账号登录、服务积分领取和权益核对由本人在 OFM 中完成，不宣传无限或永远免费。账号模式不自动启用你已停用的账号，不清除上游限流锁。

## 默认与边界

- 免费池无账号门槛，但可能限流、不稳定或受地区网络影响。默认只选择当前目录中的直接 DeepSeek 公开模型，排除 GLM、MiMo、EAC 前缀及内容未知的 combo。
- 带官方 OFM 安装并启用其总开关；只通过 OFM 自己的设置接口提交 enabled=true，不改其隐藏模型、网关、凭据和账号数据。接口不可用时报告原因，不声称已配置。
- 保留当前会话的显式思考档位。目标不支持原档位时停止，要求用户选择支持该档位的 DeepSeek，或明确指定新档位；不会把 max 静默降为 lowest。低档位通常更快，但只是说明。
- 宿主 llm/stream 中间件采用正向允许规则：只放行本 profile 已确认的 OFM DeepSeek 路由。官方提供商、其他模型和未验证 combo 在适配器流式调用前被拒绝，包括自动标题等通过该宿主服务发起的辅助调用。
- 已确认路由按聊天保存；一个聊天接入免费池、另一个接入账号渠道时互不覆盖。恢复已有聊天时复用该聊天的渠道；新聊天继承最近显式接入的渠道。没有会话归属的辅助调用只允许 profile 的默认 OFM DeepSeek 路由。
- 新会话创建时完成 DS 选模，以避免必须先使用官方模型才能理解“接入”的循环。既有或不支持创建期选模的会话可执行人工命令 onboard；不支持时说明下一步。
- 规则作用于安装本插件的 DSH profile，不控制其他 DSH 实例、外部应用或绕过宿主 LLM 服务的代码。生效前已经发出的请求不能撤销。

## 三项判据与证据

1. **模型为 DS**：目录中确认 DeepSeek 身份，宿主确认 provider/model 和可保留的原档位；status 还读取当前会话选择，不能仅靠旧配置。
2. **调用经 OFM**：在原会话观察到允许的 OFM DeepSeek 宿主调用正常完成。按宿主 sessionId 区分会话，标题和别的会话不能替代证据。账号模式额外报告是否观察到 OFM 的账号选择。
3. **轮换可用并有证据**：用 OFM 的 getAvailableAccount 排除首账号后检查能否选择不同备用；同时在真正的宿主调用上下文中只观察该现有选择接口，记录不同账号的数量和是否发生切换，不记录账号标识和凭据。预检本身不算实际切换。

只有 DS 确认、OFM 调用完成及实际账号切换证据都成立才返回 complete；两个可选账号但未发生切换仍需验证，公开池或只有一个可用账号都会说明原因及下一步。不会人为耗尽配额来制造轮换证据。

观察接口不改变账号排序、排除集、返回对象、冷却或重试，由 OFM 继续拥有全部账号调度。上游可能在一次宿主调用内做多次恢复；本地记录不推断物理请求数或实际费用。面板 API 等价估值不是余额扣款，不作为资金来源证明。

## 官方兜底

默认关闭，不自动选择。只有近期存在未恢复的 OFM 额度、认证、限频、连接或无 DS 路由等故障，并且用户主动确认时才允许：

```text
/bfy-ofm fallback --confirm-official-billing
```

无确认或当前会话无触发证据时停止并说明条件。档位不兼容、普通业务拒绝和账号数量不足不自动用官方解决。切回后仍选择 DeepSeek，但可能消耗官方余额、套餐或 API 费用；只授权当前会话，不改其他或新会话默认模型，不放开无会话归属的辅助调用，不重放之前结果未知的任务。本会话重新 onboard 关闭其官方兜底。

该确认入口是人工命令，工具不提供允许 Agent 自行批准官方费用的布尔开关。Agent 必须先取得用户对该后果的明确同意。

## 升级与验证范围

0.3.0 使用独立接入策略。旧的 config.local.json 不覆盖，新策略按 profile 写入 DSH_HOME/baifanyu-ofm/profiles/<profile>/onboarding-policy.json，避免 desktop 和 web 的证据或官方授权混用。该状态不包含提示词、账号标识或凭据。不可读时保留原件并停止调用，不静默放开官方。

真实桌面宿主已验证一次直接 DeepSeek 免费池请求，保留 high 档位并返回预期短回复，官方兜底关闭。隔离宿主中的账号轮换仍使用合成适配器，不等于真实账号的额度故障切换、账单或配额验证。账号不够或尚未取得在线验证许可时，只报告已经证明的部分。
